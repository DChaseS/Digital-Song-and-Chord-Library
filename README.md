# Digital-Song-and-Chord-Library

## 1. Problem Statement

Our music team currently shares song chord sheets and recordings through WhatsApp. While convenient, this makes it difficult to organize, retrieve and reuse resources over time.

We need a centralized, private digital platform where authorized music team members can store, organize, search and access worship songs, chord sheets and recordings.

## 2. Project Goals

- Centralize all church music resources.
- Make songs searchable and easy to retrieve.
- Allow members to upload PDF chord sheets.
- Support chord transposition.
- Allow members to upload and listen to recordings.
- Provide secure access for authorized team members.

## 3. Target Users

- Administrator: Manages the platform, members and library.
- Music Team Member: Searches, views, uploads and manages permitted resources.

## 4. Functional Requirements

- User login and authentication.
- Song creation, editing and deletion.
- Song search and filtering.
- PDF upload, viewing and downloading.
- Song genre and category management.
- Key and tempo information.
- Chord transposition.
- Audio upload and playback.
- User role and permission management.

## 5. Non-Functional Requirements

- Private access.
- Responsive interface.
- Secure file storage.
- Reliable database operations.
- Reasonable performance.
- Database and file backups.
- Maintainable and documented source code.

## 6. Project Constraints

- Zero-cost development and initial hosting.
- Small group of authorized church members.
- No paid software subscriptions.
- Web-based application.
- No public registration.
